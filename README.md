# 타마코레 한국어 · 읽기 전용

기존 번역 제작 도구와 분리한 한국어 배포용 Chrome/Edge 확장입니다. 번역된 텍스트와 PNG를 **`resources/ko.json` 한 파일**에 넣습니다. AI 호출, API 키, 제공자 설정, 편집기, 녹화기, 원격 오버레이, 자동 진행 기능은 포함하지 않습니다. 팝업에는 한국어 켜기/끄기와 업데이트 확인만 둡니다.

## 현재 상태와 검증 범위

- 확장 버전: **0.1.0**, 초기 리소스 버전: **1.0.0** (`resource-v1.0.0` 태그).
- 초기 팩: UI **12,454**건 + 스토리 **10,612**건 = **23,066**개 원문/번역 쌍, PNG **461**개. 원문과 번역의 `{USER}` 포함 항목은 각각 **26**개이며 이름을 특정 문자열로 고정하지 않습니다.
- 설치 ZIP과 업데이트 JSON은 [GitHub Releases](https://github.com/longtail7989/tamacolle-kor/releases/latest)에서 배포합니다.
- 로컬 회귀 검증 **23개**와 실제 Chromium IndexedDB 검증 **5개**를 통과했습니다. 실제 팩의 저장 후 연결을 두 번 다시 열어 23,066개 텍스트·461개 PNG가 유지되는 것도 확인했습니다.
- 별도 검증 브라우저의 실제 Cocos Creator 2.1.1에서 게임 로그인 버튼 PNG와 임시 검증 Label·아이콘을 사용했습니다. 통제된 GitHub HTTP 응답으로 `1.0.0 → 1.0.1 → 1.0.2`의 다운로드·검증·저장·현재 화면 교체, Off 중 원문 유지와 다음 On 적용, 같은 버전의 JSON 재다운로드 생략을 확인했습니다. 임시 데이터는 배포 팩에 넣지 않습니다.
- GitHub 배포 결과는 Release 자산과 Actions 실행 기록에서 확인할 수 있습니다. 로그인된 스토리 전 구간과 Edge에서는 별도 실사용 검증을 하지 않았습니다.

## 설치

[최신 Release](https://github.com/longtail7989/tamacolle-kor/releases/latest)에서 설치 ZIP을 받아 다음과 같이 설치합니다. 아래 제작 명령으로 로컬 ZIP을 생성할 수도 있습니다.

1. `tamacolle-kor-0.1.0-extension.zip`을 내려받아 별도 폴더에 압축을 풉니다. JSON만 받는 것은 최초 확장 설치가 아닙니다.
2. `chrome://extensions` 또는 `edge://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다. `manifest.json`이 있는 폴더를 지정합니다.
3. **기존 `tamacolle-translator` 번역 제작 확장이나 다른 타마코레 번역 확장은 끕니다.** 같은 게임 객체에 중복 후킹하면 충돌할 수 있습니다.
4. 게임을 열고 도구 모음의 확장 팝업에서 한국어를 켭니다. 설치 당시 이미 열려 있던 게임 탭은 한 번 새로고침하여 확장 코드를 로드합니다.

기존 제작용 확장의 프로필, 개인 캐시, 자격 증명은 가져오지 않습니다. 제공된 항목에 없는 문구는 원문으로 남습니다.

## 켜기/끄기와 업데이트

사용 동작은 다음과 같습니다.

- **한국어 켜기/끄기**: 켜면 제공된 번역과 이미지 패치를 적용하고, 끄면 원문 텍스트/이미지/글꼴로 되돌립니다.
- **업데이트 확인**: 고정된 [이 저장소의 최신 정식 Release](https://github.com/longtail7989/tamacolle-kor/releases/latest)에서 `tamacolle-kor-resources.json`만 확인합니다. 수동 확인 외에 하루 단위 자동 검사를 수행하도록 구성합니다. 아직 Release가 없으면 미게시로 표시하며 현재 팩을 유지합니다.
- 새 JSON은 크기, 형식, 버전, 텍스트 보호 토큰, PNG 메타데이터·크기·SHA-256 및 GitHub 자산의 `sha256:` digest를 검사한 뒤 저장합니다. 실패한 다운로드나 낮은 버전으로 현재 팩을 교체하지 않습니다. 체크섬 파일은 수동 확인용이며 자동 업데이트의 신뢰 기준은 GitHub API가 제공하는 자산 digest입니다.
- **리소스만 변경**하면 게임을 다시 로드하지 않고 현재 텍스트와 PNG를 다시 적용합니다. 한국어가 꺼져 있을 때는 데이터만 갱신하고, 다시 켰을 때 적용합니다. 검증 범위는 위 항목과 같습니다.
- **확장 코드 변경**은 JSON 업데이트로 설치되지 않습니다. 새 ZIP의 파일로 교체한 뒤 확장을 다시 로드해야 하며, 새 코드를 게임 탭에 넣으려면 탭 새로고침이 필요할 수 있습니다. 더 높은 확장 버전을 요구하는 팩은 먼저 코드 업그레이드가 필요합니다.

JSON 팩에는 실행 가능한 코드가 없습니다. 번역을 위해 외부 AI 서비스에 게임 문장을 보내지 않습니다. 업데이트 확인에는 GitHub 연결이 필요합니다.

## 리소스 원본과 안전 제외

초기 팩은 기존 제작 프로젝트의 공개 파일 `tamacolle-fixed-ui-ko.json`, `tamacolle-main-story-ko.json`, `image-catalog.js`와 카탈로그에 명시된 `image-patches/*.png`만으로 만듭니다. 야마토 아이콘 16/32/48/128px도 제작 프로젝트의 공개 아이콘을 사용합니다.

원문, 번역, 스토리 문맥과 공백은 유지하고 제작용 ID·시간·대상 언어 필드는 배포 항목에서 제거합니다. `{USER}`, 숫자, 태그, 변수, 줄바꿈의 보호 규칙을 유지합니다. 카탈로그의 원본 식별자·영역·해시 메타데이터는 보존하며 PNG 실제 바이트를 JSON에 넣습니다. 이미 공개 스토리 파일에서 제외된 **안전하지 않은 스토리 원문 129건은 복원하지 않습니다.** 모든 문구나 모든 이미지에 대한 번역 완성을 뜻하지 않습니다.

## 로컬 생성과 배포

Node.js **22** 이상을 사용합니다. 외부 npm 의존성 설치는 필요하지 않습니다.

```powershell
node scripts/import-translator.mjs --from C:/Users/longtail/Desktop/tamacolle-translator --version 1.0.0
node --test tests/resources.mjs tests/runtime.mjs
node scripts/build.mjs --tag resource-v1.0.0
```

가져오기는 지정한 제작 폴더를 읽기만 하고 이 저장소의 `resources/ko.json`만 갱신합니다. 공개 카탈로그 JS는 실행하지 않고 고정 래퍼 안의 JSON 배열만 파싱합니다. 팩의 최소 확장 버전은 `0.1.0`으로 기록합니다.

빌드 출력:

- `dist/tamacolle-kor-0.1.0-extension.zip`: 명시적 허용 목록의 코드/아이콘과 `resources/ko.json`만 포함하는 결정적 ZIP.
- `dist/tamacolle-kor-resources.json`: `resources/ko.json`과 **바이트가 같은** 업데이트용 단일 JSON.
- `dist/SHA256SUMS`: ZIP과 JSON의 SHA-256.

ZIP의 정렬, 날짜, 파일 속성은 고정됩니다. 문서, 테스트, 원본 제작 파일, 프로필, `.git`, 비밀 설정은 ZIP에 넣지 않습니다. 빌드는 팩을 엄격하게 검증하고 `--tag`가 팩 버전과 다르면 거부합니다.

`.github/workflows/release.yml`은 `resource-v*` 태그에서 리소스·런타임 테스트를 실행한 뒤 빌드하고 위 세 자산을 정식 Release에 게시합니다. `resource-v1.0.0`은 팩 `1.0.0`과 일치해야 합니다. 토큰은 GitHub Actions의 일시적 토큰만 사용하고 파일에 저장하지 않습니다. 워크플로 파일이 있다는 것 자체는 원격 실행이나 게시 성공의 증거가 아닙니다.

게임·캐릭터·원본 UI의 권리는 원저작권자에게 있습니다. 비공식 한글화 도구이며 공식 번역이나 운영사 제휴 제품이 아닙니다.
